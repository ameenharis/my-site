# ameenharis.github.io/my-site

My portfolio site: **[ameenharis.github.io/my-site](https://ameenharis.github.io/my-site/)**

It's one page, and it changes its look for every section: a lab notebook for the intro, a cricket scoreboard, a weather office, a night-time car dashboard, a field guide, a cinema, a status page, an eye chart, and a letter to finish.

## How it's built

- A single `index.html`: plain HTML, CSS and JavaScript, no frameworks or build step
- Fonts from Google Fonts
- Hosted on GitHub Pages from the `main` branch
- Respects "reduce motion" settings and works on mobile

## Running it locally

Open `index.html` in a browser. That's it.
